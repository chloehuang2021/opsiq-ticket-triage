## Features

* AI-powered ticket analysis and categorization
* Ticket creation and management
* Dashboard metrics
* Ticket search
* Status filtering
* Status updates (Open, In Progress, Resolved)
* Created and updated timestamps

## Architecture

Frontend (Angular)
        |
        v

        |
        v
